# collab-richtext-go

多人实时协同富文本编辑内核（纯本地实现，不依赖外部服务）。
多个参与者同时编辑同一份文档时，各端最终看到一致的正文与格式，
并能实时看到彼此的光标与选区。内置回环传输层，可复现乱序、重复、
丢包与断线重连。

## 结构

| 包 | 职责 |
|---|---|
| `crdt` | 文档内核：RGA 序列、墓碑删除、区间属性 LWW、版本向量、历史压缩、快照 |
| `presence` | 参与者在线状态（光标/选区），TTL 超时清理 |
| `transport` | 本地回环网络：丢包/重复/延迟乱序注入，断线重连 |
| `session` | 端点：同步协议、离线补发、缺口修复、心跳、快照持久化 |

## 收敛规则

### 文本增删（RGA）

- 每个字符节点有全局唯一 ID `(Seq, Site)`，插入操作引用其左邻节点 ID。
- 并发插入同一位置时，新节点越过所有 ID 更大的并发兄弟节点，
  因此同一组操作无论以什么顺序应用，结果都相同。
- 删除是墓碑标记；并发删除同一字符只生效一次。
- 每个操作由 `(Site, Seq)` 唯一标识，重复投递直接忽略，绝不二次生效。
- 操作依赖未满足（父节点未到、序号有空缺）时进入待处理缓冲，
  依赖补齐后自动应用，因此乱序投递不影响最终一致性。

### 区间属性（加粗、斜体等）

- 属性操作作用于 **ID 区间** `(Start, End)` 而非位置区间，
  与并发增删合并后结果确定。
- 同一节点同一属性按 `(Lamport, Site)` 做 Last-Writer-Wins 仲裁，
  与到达顺序无关。
- 并发插入落在属性区间内的字符会继承该属性：属性操作永久保留
  （含在快照中），迟到的插入到达时重新匹配所在区间，
  因此“先设属性后收到插入”与“先收到插入后设属性”结果一致。
- 属性取消是写入空值的 LWW 记录。
- 墓碑节点上的属性变化只影响墓碑本身，渲染不可见，
  不会牵连仍然存活的内容。

### 历史补齐与压缩

- 每个端点维护版本向量（每 Site 的最大 Seq）。
- 重连/加入时广播 `sync-req`（携带本地版本向量），对方回发缺失的
  操作区间（`sync`）；发现序号缺口时也会主动向来源请求补齐。
- `Compact()` 把当前历史压入基线；此后对过旧版本的 `sync-req`
  直接回发快照。压缩不影响与持有完整历史的一端继续收敛。
- 新加入者通过“快照 + 增量”对齐：先从任一端拿到快照，
  后续增量操作幂等合并。

## 在线状态生命周期

- `UpdatePresence` 更新本地光标/选区并立即广播；心跳按
  `HeartbeatInterval` 周期重播（天然容忍丢包）。
- 参与者 `Close()` 时广播 `bye`，各端立即移除其状态。
- 异常掉线（无 `bye`）时，状态在 `PresenceTTL` 未心跳后自动清理。
- 在线状态是**临时状态**：不进入操作日志、不写入快照，
  快照恢复后在线状态为空。

## 可调参数

### transport.Config

| 参数 | 含义 |
|---|---|
| `DropRate` | 每条消息丢弃概率 [0,1] |
| `DupRate` | 每条消息额外复制概率 [0,1] |
| `MinLatency`/`MaxLatency` | 投递延迟区间；区间 >0 时产生乱序 |
| `Seed` | 随机种子；固定后故障注入序列确定，可确定性重放 |

### session.Config

| 参数 | 含义 |
|---|---|
| `HeartbeatInterval` | 在线状态心跳间隔；0 关闭 |
| `PresenceTTL` | 在线状态超时；超时未心跳自动清理 |
| `ResyncInterval` | 周期重同步间隔（丢包自愈的重试策略）；0 关闭 |

## 并发安全

- `crdt.Document` 全部导出方法并发安全：远端应用（写）与本地读取、
  快照生成分离为互斥/读锁，任何时刻都读不到半截状态。
- `session.Peer` 的消息处理、本地编辑、快照恢复均串行化。
- 测试包含 `-race` 下的并发读写 + 快照场景（`session/race_test.go`）。

## 确定性重放

固定 `transport.Config.Seed`、固定操作脚本、关闭时间相关心跳时，
整个系统的消息决策序列确定，重放结果一致
（见 `session.TestDeterministicReplay` 与 `crdt.TestDeterministicReplay`）。

## 测试

```sh
go test ./... -count=1
go test ./... -race -count=1
```

覆盖：并发插入/删除收敛、重复投递幂等、乱序与跨端依赖、
属性与增删并发、属性 LWW、离线编辑重连合并、快照恢复与新加入者对齐、
历史压缩后继续收敛、在线状态传播/离开/超时清理、
乱序+重复+丢包故障注入下的多端收敛、并发读写与快照（-race）。
